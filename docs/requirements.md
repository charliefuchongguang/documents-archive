# 需求收集文档

> 状态：✅ 已确认

## 需求概述
一个公路行业招标代理公司的项目档案归档管理工具。用户上传招标公告截图、招标文件、评标报告、中标通知书、中标公示、履约评价、代理服务合同等归档文件后，系统自动从文件中提取关键信息，填入标准化的项目档案管理表中，减少人工录入工作量。

## 核心功能
1. **前端页面上传文件**：支持上传招标公告截图、招标文件、评标报告、中标通知书、中标公示、履约评价、代理服务合同等归档文件
2. **自动信息提取**：从上传的文件中智能提取项目编号、项目名称、招标方式、中标单位、中标金额、公告时间等关键字段
3. **提取结果展示与复核**：将提取的信息以表单形式展示，供用户核对、修改和补充
4. **同步至企业微信智能表格**：用户确认无误后，一键将数据写入企业微信智能表格，完成归档

## 使用方式
企业微信自建应用，用户通过企业微信工作台打开应用页面，上传归档文件并完成信息录入

## 开发工具
Qoder

## 条件与限制
- 输入文件统一为 Markdown 格式（用户预先用 MinerU 将 PDF/图片等转换为 .md）
- 无其他特殊限制
