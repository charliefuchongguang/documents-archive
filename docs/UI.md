## 一、整体风格

- **风格**：简洁专业、卡片式布局
- **主色调**：白底 + 企业微信蓝（#2B7AF6）作为强调色，绿色表示成功/完成，橙色表示警告/待处理
- **字体风格**：系统默认字体（PingFang SC / Microsoft YaHei），保持企业微信原生体验

## 三、交互设计

### 新建项目的交互

| 用户操作 | 界面反应 | 说明 |
|----------|----------|------|
| 点击「+新建」 | 弹出输入框，默认填充「未命名项目+当前日期」 | 用户可直接确认或修改名称 |
| 输入名称后确认 | 创建项目，跳转至项目详情页 | 项目状态为「进行中」 |
| 点击项目卡片 | 进入该项目详情页 | 卡片整区域可点击 |

### 文件上传的交互

| 用户操作 | 界面反应 | 说明 |
|----------|----------|------|
| 点击「选择文件」 | 唤起系统文件选择器，仅允许 `.md` 文件 | 过滤文件类型 |
| 选择文件后 | 显示文件名，状态变为「已上传」，出现「提取」按钮 | 文件内容读入内存 |
| 点击「提取」 | 按钮变为加载状态「提取中...」，显示进度条 | 调用 DeepSeek API |
| 提取成功 | 显示「✅ 提取完成，XX个字段已识别」，右侧预览区更新 | 提取结果存入 IndexedDB |
| 提取失败 | 显示具体错误（如「API Key 无效」「网络超时」），提供「重试」 | 不清除已上传文件 |
| 点击「重新上传」 | 清除该类型的已上传文件和提取结果，回到未上传状态 | 二次确认提示 |

### 复核表单的交互

| 用户操作 | 界面反应 | 说明 |
|----------|----------|------|
| 点击分组标题 | 展开/折叠该分组 | 默认展开有数据的分组 |
| 修改字段值 | 字段边框变蓝（已修改标记） | 与原始提取值区分 |
| 遇到冲突字段 | 显示冲突提示条：「招标文件: XX / 中标通知书: YY」，用户选择采用哪个 | 高亮显示 |
| 点击「保存草稿」 | 提示「草稿已保存」，数据存入 IndexedDB | 可中途退出后续填 |
| 点击「提交至智能表格」 | 弹出确认框「确认提交以下 XX 个字段？」，确认后调用 API | 如有空必填字段，先提示补全 |

### 设置弹窗的交互

| 用户操作 | 界面反应 | 说明 |
|----------|----------|------|
| 点击「⚙️」 | 弹出设置弹窗 | 弹窗居中显示，背景蒙层 |
| 输入 API Key | 密码模式显示，可点击 👁 切换可见 | |
| 点击「测试连接」 | 调用 DeepSeek 简单请求，显示 ✅ 或 ❌+错误信息 | |
| 点击「保存」 | 存入 localStorage，提示保存成功，关闭弹窗 | |
| 首次打开应用无 Key | 自动弹出设置弹窗，显示引导文字 | 引导用户申请 DeepSeek Key |

## 四、组件清单

| 组件 | 用途 | 备注 |
|------|------|------|
| 顶部导航栏 | 全局导航 | 固定定位，含返回/标题/操作按钮 |
| 项目卡片 | 首页展示项目 | 显示进度、状态、时间 |
| 文件上传卡片 | 详情页文档上传区 | 每类文档一个卡片，含状态指示 |
| 步骤/进度条 | 显示整体完成度 | 4/6 文件已处理 |
| 表单输入框 | 复核页字段编辑 | 支持文本、下拉、日期等类型 |
| 折叠面板 | 复核页字段分组 | 6个逻辑分组，可展开折叠 |
| 冲突提示条 | 多来源字段冲突 | 显示不同来源的值供选择 |
| 空字段标记 | 未提取到的字段 | 黄色背景 + 「未找到」提示 |
| 按钮（主/次/危险） | 各种操作 | 主按钮蓝色，次按钮灰色，危险操作红色 |
| 加载状态 | API 调用中 | 按钮转圈 + 禁用 |
| Toast 提示 | 操作反馈 | 成功/失败/警告的轻量提示 |
| 确认弹窗 | 二次确认 | 删除、提交等关键操作前确认 |
| 设置弹窗（Modal） | API Key 配置 | 见下方详细设计 |
