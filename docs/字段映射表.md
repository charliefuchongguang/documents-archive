## 关键观察

1. **字段之间存在交叉验证关系**：如项目名称需与中标通知书一致，招标人出现在多份文档中可互相校验
2. **枚举值字段**：项目类型、招标方式、建设类型、道路等级、盖章单位等有固定选项，提取后可做校验
3. **长文本字段**：项目概况为长文本，可能需要特殊处理
4. **金额字段**：总投资、委托金额、中标金额等需注意单位统一为"万元"
5. **日期字段**：公告时间、委托时间、公示时间、中标通知书时间、评价书出具时间等需注意格式统一
