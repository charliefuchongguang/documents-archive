# 省道宁应线铺龙湾至陈家堡段改建工程施工监理招标(1标段)招标公告

（招标编号：E14060000G3000715002）

招标项目所在地区: 山西省朔州市怀仁市

# 一、招标条件

本省道宁应线铺龙湾至陈家堡段改建工程施工监理招标（招标项目编号： E14060000G3000715002 ），已由山西省发展和改革委员会批准，项目资金来源为上级补助资金和怀仁市政府筹措资金，招标人为山西省公路局朔州分局。本项目已具备招标条件，现进行 公开招标 。

# 二、项目概况和招标范围

项目规模: 省道宁应线铺龙湾至陈家堡段改建工程起点为大同市左云县与朔州市怀仁市交界，省道宁应线K59+995处，向南沿既有公路展线，经铺龙湾、吴家窑，下穿运煤铁路，绕过规划的大峪口水库，于大峪口村附近接回原省道沿既有路展线，至陈家堡村下穿省道大忻线后，与国道208线十字交叉，接省道宁应线K72+068处。路线全长11.855公里，全线采用二级公路技术标准，设计速度60公里/小时，路基宽度12米，中桥4座桥长272米，小桥1座8米，桥涵设计汽车荷载等级采用公路-I级。招标内容与范围：本招标项目划分为1个标段，本次招标为其中的:

# 001第一标段:

省道宁应线铺龙湾至陈家堡段改建工程施工阶段（含施工准备阶段）、验收与缺陷责任期阶段的施工监理。本招标项目划分为1个标段，标段划分如下：

001第一标段：省道宁应线铺龙湾至陈家堡段改建工程施工图范围内全部工程的施工监理。

监理服务期：37个月，1127日历天。施工期监理（含施工准备期）：13个月，缺陷责任期监理：24个月；

# 三、投标人资格要求

# 001第一标段:

3.1本次招标要求投标人持有有效的企业法人营业执照，同时满足下列资质、业绩和总监理工程师要求，并在人员、设备等方面具有相应的施工监理能力。

3.1.1资质要求：

投标人须同时具备以下资质：

①交通运输部核发的公路工程乙级或以上监理资质，并且合法有效。

②交通运输主管部门颁发的公路工程综合乙级或以上试验检测机构资质（试验检测资质证书中的机构名称应为投标人名称，若与投标人名称不一致时，其应为投标人不具有独立法人资格的下属机构，或与投标人为存在控股、管理或投资参股关系的机构，或法定代表人与投标人法定代表人为同一人的机构），并且合法有效。

3.1.2业绩要求：

近5年（2018年9月1日至投标文件递交截止前一日，以交工时间或竣工时间为准）至少独立完成过以下施工监理业绩：

（1）1项里程不少于10公里的二级或以上新（改、扩）建公路且同时包含路基、路面（沥青混凝土）工程施工监理业绩；

（2）1项中桥或以上桥梁工程施工监理业绩。

注：当投标人企业业绩能够同时满足多个业绩要求时，可分别予以认定。

3.1.3总监理工程师要求：

总监理工程师1名，具有高级工程师或以上技术职称（公路相关专业），具有交通运输部颁发的监理工程师资格（已在投标人处进行岗位登记）或持有人力资源和社会保障部颁发的交通运输工程监理工程师职业证书且注册单位名称为投标人，且至少担任过1项里程不少于10公里新（改、扩）建二级或以上公路且同时包含路基、路面（沥青混凝土）工程施工监理的总监理工程师(或驻地监理工程师)。

投标人企业业绩、总监理工程师的个人业绩应是已列入交通运输部“全国公路建设市场信用信息管理系统”或“山西省公路水运市场管理平台”中公开的业绩。

3.2本项目不接受联合体投标。

3.3关联关系

3.3.1投标人与招标人存在利害关系且可能影响招标公正性的不得参加本项目投标。

3.3.2投标人具有下列情况之一的，不得同时参加同一标段投标，否则其投标均无效：

①单位负责人为同一人或者存在控股、管理关系的不同单位；

②具有投资参股关系的关联企业；

③董事、监事、总经理、副总经理和财务负责人相互兼职的关联企业。

3.4凡被交通运输部或山西省交通运输厅取消或暂停工程投标资格的施工监理单位，在处罚期内无资格参与本项目的投标。

凡在交通运输部或山西省公路建设市场信用评价的考核定级中，被评价为D级的单位，在处罚期内无资格参与本项目的投标。

3.5投标人未在“中国执行信息公开网”中被列入失信被执行人名单。

3.6投标人未在国家企业信用信息公示系统中被列入严重违法失信企业名单。

3.7投标人及其法定代表人、拟担任本项目的总监理工程师近3年（2020年9月1日至投标文件递交截止日）无行贿犯罪行为。

3.8投标人不得为本项目工程施工承包人（含中标人或中标候选人），或与其具有3.3.2的关联关系，否则投标人投标无效。

本标段 不允许 联合体投标。
